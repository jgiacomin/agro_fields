# Objetivo

Definir la arquitectura para capturar, estructurar y validar oportunidades agropecuarias provenientes de fuentes externas antes de convertirse en Activos Agro V2.

---

# Problema identificado

Actualmente las oportunidades agropecuarias se encuentran distribuidas en diferentes canales:

- publicaciones de Facebook;
- grupos especializados;
- WhatsApp;
- inmobiliarias;
- brokers;
- contactos personales.

La información disponible generalmente se presenta sin una estructura uniforme y con diferentes niveles de confiabilidad.

---

# Objetivo estratégico

Transformar información dispersa del mercado agropecuario en oportunidades digitales estructuradas.

El objetivo no es reemplazar los canales actuales, sino crear una capa de organización, validación y confianza sobre la información existente.

# Concepto Oportunidad Agro

Una Oportunidad Agro representa una posible unidad productiva o activo detectado externamente que todavía no posee una validación completa dentro del ecosistema Agro Fields.

Puede representar:

- campos;
- establecimientos productivos;
- explotaciones agropecuarias;
- recursos asociados al territorio;
- proyectos productivos;
- oportunidades de inversión.
